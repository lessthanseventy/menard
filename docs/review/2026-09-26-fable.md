# Fable review of lib/, 2026-09-26

Nine read-only Fable reviewers, "as José Valim would review a PR", one area each. Their findings as
reported, not yet verified here except where a reviewer says it reproduced one. Nothing is fixed
yet; each fix is its own commit, with a test that goes red first.

## Architecture (whole lib/)

- **Every verb is written twice**, once per door: `Mix.Tasks.Menard.Clause.verb/2` and
  `Menard.MCP.Clause.call/2` (mcp/tools.ex:201-313), and likewise for each noun. They have drifted:
  `attr list` is text in the CLI and a map in MCP; `clause move` has no version or stages in either;
  the MCP `rename` drops per-file errors (tools.ex:107-121); the Phoenix `attr :x` hint is MCP-only;
  `guard`, `map`, `where`, `version` exist only as mix tasks.
- **Seven return conventions**: a bare binary or `{:error, msg}`; `{:ok, _}`; `{:error, :missing}`;
  raw Sourceror error terms; `ok:` maps; `Menard.format`'s `{:error, _}` meaning "written, not
  formatted"; raises and blanket rescues. Proposed rule: core returns `{:ok, reply} | {:error,
  reason}`, only doors raise, exit or print.
- **Clause is the de-facto AST layer**: `module_scope/2`, `module_body/1`, `modules/1`, `squash/1`,
  `bare_head/1`, `comment_at/4` are `@doc false` publics used by 8 other modules (17 call sites).
  They belong in `Menard.Source`.
- **Primitives re-derived per verb**: `patch/3` ×5, `comment_lines_above` ×3 beside Source's,
  `dedent`, `indented`, `start_line`, `name_arity`, `drop_lines`, `slice`. `Source.range/2` holds
  the fixes for the "range one column short" bug class, yet Block calls raw `Sourceror.get_range`
  11 times, Directive 5, Rename 5, Attr 4. Three parse entry points.
- **Hidden state**: host beams loaded into menard's VM, `:persistent_term` erasure, a global cwd lock
  (menard.ex:144-377); Process-dictionary parse cache and Run's deadline/log; a copy of every written
  file under the user cache; the green stamp in the host's `.git` (hook glue in a read verb).
- **Delete**: `Write.run/2` (no caller), the prose verbs (`clause doc|comment`, `attr comment`,
  `module comment`, ~250 lines) if the guard lets comment-only edits through, `attr replace` and
  `replace_body` aliases.
- **Order**: (1) one verb layer under both doors plus one error rule, medium; (2) module walking into
  Source, one `range`/`patch`/`parse`, medium; (3) the host formatter out of menard's VM (OS process
  only), large.

## Core (menard.ex, source.ex, diff.ex, write.ex, move.ex)

1. menard.ex:207-213 — **bug**: the shell `mix format` fallback has no timeout; `format_staged`
   kills the Elixir task at 60 s but the OS `mix format` runs on and can overwrite the file after
   menard handed out its version, so the agent's next edit is refused as stale. Thread the deadline
   into `host_mix(root, args, timeout: ms)`.
2. menard.ex:405 vs 91-93 — the no-Mix (release) branch cannot work: `write/3` calls `Mix.shell()`
   unconditionally. Delete the branch or drop the dependency.
3. menard.ex:109-136 — **perf**: every `format/2` re-evals `.formatter.exs`, re-globs ebins, copies
   deps' formatter files; `run format` pays it per file. Hoist per-root setup.
4. source.ex:224-262 — **perf**: `range/2` materialises the rest of the file as graphemes for every
   string in the node. Filter to strings ending at the range end; scan lazily.
5. move.ex:13-23 — `move` drops both write replies: no version or stages for either file.
6. write.ex:14-32 — `Write.run/2` has no caller; `checked/2` is the live API with no doc or spec;
   `line/1`'s integer clause is unreachable.
7. menard.ex:56-58 — `format_content/3` has no caller.
8. menard.ex:79-84 — a `:waiting_on` message is left in the caller's mailbox on success.
9. source.ex:110-121 — `with` with the happy path in `else`; `with true <-` that is an `if`.
10. menard.ex:490-520 — mise lookup computed twice; a guard on an outer variable.
11. menard.ex:304-306 — **bug (minor)**: `remember/1` `File.stat!`s cached versions; two menard
    processes pruning at once can fail a write that already landed. Use `File.stat/2`.
12. source.ex, clause.ex:923, attr.ex:182 — `dedent`/`shared_indent`, `comment_lines_above` ×3.

## Hooks (bugs reproduced in a scratchpad)

1. commit-gate.sh:11 — **bug**: the `git commit` regex misses `git -C "my dir" commit`,
   `git --no-pager commit`, `git --git-dir=x commit`, `if …; then git commit`, `env A=1 git commit`,
   `time git commit`, `bash -c "git commit"`. Widen the prefix class and the global options.
2. stop-gate.sh:42-46 — **bug**: `blocks` is never cleared on green: three early refusals switch the
   stop gate off for the rest of a long session. `rm -f "$blocks"` when green.
3. format-report.sh:85-88 — **bug**: when one file fails to parse, the reformat report of the other
   files in the same call is dropped, so the next Edit is written against a stale read.
4. format-report.sh:27,53,61 — **bug**: one menard start per file (format 0.46 s, credo 1.2 s); a
   `git checkout` touching 100 files takes ~170 s, past the 60 s hook default, and the agent hears
   nothing. One `run format` and one credo per project with all files; skip `git` commands.
5. stop-gate.sh:31, commit-gate.sh:32 — **bug**: the gates own no deadline (the 300 s is only in
   eval/run.py); a killed hook fails open and its `mix test` outlives it. `timeout --kill-after=5
   280`, block on 124, and ship the wiring with `"timeout": 300`.
6. format-report.sh:16-21 — **bug**: the mark is per session, not per call: two concurrent Bash calls
   race and a file written before the second mark goes unformatted. Key on `tool_use_id`.
7. shell-edits.sh:31 — **bug**: `find -print | xargs grep` splits paths on spaces. `-print0 | xargs -0`.
8. format-report.sh:78 — **bug**: `grep "^$dir|"` treats the path as a regex; `[x]` in a path drops
   every compile warning. Compare with awk.
9. commit-gate.sh:18-39 — gates every touched project whatever the repo: a commit in repo 2 waits
   on (and is denied for) repo 1.
10. Duplication for one sourced `hooks/lib.sh`: session sanitize and paths (4 scripts), the `why=`
    block, the mix.exs walk, the prune list, two spellings of the menard path (one no-ops from a
    checkout); format-report.sh:60 re-implements `credo?/1`.
11. format-elixir.sh — superseded by format-report.sh, wired nowhere; only its test (failing,
    TODO.md:6) keeps it. Delete both.
12. `*'"ok":true'*` substring where `jq -e .ok` on the last line belongs (with `2>&1`, a stderr line
    could pass a gate); the reformat diff drops removed lines starting `--` and truncates at 40
    without a marker.
